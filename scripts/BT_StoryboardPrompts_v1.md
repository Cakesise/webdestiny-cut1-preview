# 《丝途》试播集01《断线之夜》分镜生成提示词 v1

统一输出：16:9 横版电影分镜接触表，每张包含五个独立画格，前三格在上排、后两格在下排；画格之间使用干净黑色窄分隔线；不得出现标题、编号、字幕、文字或水印。每个画格都是写实电影剧照，不是草图，不是漫画，不是海报拼贴。人物、服装、魔杖、场景与电蓝色丝线遵循 `BT_ContinuityBible_v1.yaml`。

## BT-01 宇宙钩子·断线（00:00–00:10）

1. 宏大远景：黑暗宇宙中无数纤细电蓝丝线交织成三维网络，能量节点像星辰呼吸。
2. 极近特写：其中一根丝线突然崩断，断口迸发冷白蓝光与微小星屑。
3. 中近景：古老青铜机械蜘蛛“织客”从虚空阴影中睁开多枚镜片眼，关节开始活动。
4. 动作特写：织客前足夹住断线，身体发力向后拉，另一截丝线剧烈震颤。
5. 城市大全景：断线化作一道蓝白光束刺入现代亚洲城市夜空，高楼与云层被短暂照亮。

连续性：纯宇宙异象，无人物；蓝色丝线由细密网络逐渐收束为一根刺向城市的断线。

## BT-02 尚班第一次看见异常（00:10–00:20）

1. 宽幅建立镜头：深夜高层建筑事务所，尚班伏在木桌建筑图纸上工作，暖台灯照亮手与纸，窗外城市冷蓝。
2. 背影中景：他察觉窗外异常，放下铅笔并起身走到落地窗前，灰风衣下摆仍有动作趋势。
3. 眼镜特写：尚班推高圆框眼镜，镜片里倒映出一根不合逻辑的电蓝丝线。
4. 过肩近景：他抬起手机或建筑测绘屏幕验证，蓝色异常线穿过正常城市坐标网格。
5. 侧面中景：尚班站在窗边凝视远方天际线，画面深处的蓝线正缓慢下降，他冷静但明显警觉。

连续性：尚班固定人设与灰风衣；同一办公室、同一窗外城市方向；由桌边移动到窗边，结束时面向异常。

## BT-03 罗兰登场·相遇（00:20–00:30）

1. 雨夜远景：狭长旧街巷，罗兰独自从远端走入画面，黑色短发的银白后颈发尾清晰可见，湿石板倒映橙色路灯与冷蓝魔光。
2. 低机位动作特写：黑色厚底靴踩过水洼，棕色斜挎包随步伐摆动，一根蓝色丝线从她脚边向前延伸。
3. 侧面近景：罗兰抬手夹住悬浮蓝线，雨水沿短发与黑夹克滑落，她锐利地追踪线的方向。
4. 美型面部特写：白净可爱的成年罗兰回头，暖棕色眼睛映着魔光，黑色短发的银白后颈发尾被雨水打湿，神情从专注转为戒备。
5. 平衡双人中景：罗兰与刚走入巷口的尚班隔着数米对峙，两人都在移动后的停顿状态，视线越过发光丝线相撞。

连续性：罗兰保持同一脸、黑色分层短发与银白后颈发尾、夹克、短裤、中筒袜、靴子、星形配饰与斜挎包；尚班延续上一段服装；雨势、路灯方向和蓝线走向一致。

## BT-04 三人关系建立·魔杖漂浮（00:30–00:40）

1. 宽幅三人关系镜头：魔法阁楼长木桌旁，尚班坐在左侧摊开城市图，罗兰坐在右侧身体前倾，因素坐在桌端观察，深色木魔杖横放桌面中央。
2. 尚班中景：他用铅笔指向地图上的异常路线，另一只手压住卷起图纸，语气理性；罗兰在画面边缘不耐烦地换坐姿。
3. 罗兰近景：她挑眉反驳并抬起一根手指，身体向桌前倾，眼神仍锁定尚班，不做静态摆拍。
4. 因素近景：奶奶轻轻抬手制止争执，温和微笑，深蓝外套的细小星图刺绣被暖灯照亮。
5. 桌面低角度：魔杖突然从桌面升起并轻微旋转；尚班立即后仰观察，罗兰伸手想抓，因素保持抬手控制，三人反应各不相同。

连续性：固定阁楼桌位和暖灯方向；多人物镜头中三人均有逻辑动作；魔杖从桌面静止变为悬浮。

## BT-05 罗兰操控魔杖·失控前兆（00:40–00:50）

1. 美型近景：罗兰站在阁楼高窗旁，白净面孔与银白后颈发尾被蓝光勾边，她带着自信又顽皮的微笑看向悬浮魔杖。
2. 极近特写：她苍白纤细的手指捏住深色木魔杖，杖身金属纹路被电蓝火花依次点亮。
3. 动作中景：罗兰向前挥动魔杖，夹克下摆与斜挎包被能量气流轻轻掀起，蓝线沿弧线追随。
4. 手部与表情组合近景：丝线突然反向缠住她的手腕和魔杖，她的自信开始崩裂，手臂本能向后收。
5. 面部大特写：魔杖在她脸前高频震颤并爆出密集蓝光，罗兰睁大眼吸气，背景阁楼被压暗，危险即将发生。

连续性：本段尽量只出现罗兰；动作从抓住、挥动到被反噬；结束状态直接衔接下一段的丝线爆发。

## BT-06 魔法事故·世界裂开（00:50–01:00）

1. 冲击近景：魔杖在罗兰面前爆发成放射状电蓝丝线，她抬臂护脸，短发和夹克被气浪掀动。
2. 低机位中景：蓝线缠住罗兰的手腕、腰与椅背，将她猛地拖倒在椅边，她失去平衡但脸与服装保持稳定。
3. 动态三人镜头：尚班从桌侧冲来伸手想拉断丝线，因素同时从座位起身抬手施法，两人都在行动，罗兰被持续拉扯。
4. 因素与魔法特写：奶奶在尚班肩后精准截断一束蓝线，断口化作星屑；尚班护住罗兰，罗兰仍试图挣脱，三人动作互相影响。
5. 终局城市大全景：阁楼窗外的现代城市与一座宏伟魔法学院半透明重叠，电蓝丝线横贯天际；窗内仅见三人小小剪影，现实被撕开。

连续性：从上一段的面前震颤直接进入爆发；丝线先束缚罗兰，再被因素切断；结尾将室内蓝光延续到城市与魔法学院叠影。
