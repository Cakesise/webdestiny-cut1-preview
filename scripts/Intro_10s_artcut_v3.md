# 《WebDestiny》十秒电影片头 v3｜艺术快剪版

## 节奏

- 无解说、无对白、无歌词。
- 原创 144 BPM 魔法管弦乐，约每 0.42 秒一个明显节拍。
- 五个主画面落点：0.00、2.08、4.17、6.25、8.33 秒；10.00 秒最终重音。
- 每个角色段落由 3–4 个短镜头组成，使用特写插帧、跳切、速度拉升和硬切，禁止慢溶解。

## 快剪结构

### 0.00–2.08 秒｜罗兰

裂缝全景 → 罗兰眼睛特写 → 星形耳坠闪光 → 靴子落地 → 飞书遮满镜头。剪辑随钟琴和低音鼓逐拍加速。

### 2.08–4.17 秒｜尚班

飞书硬切为黑板粉笔特写 → 尚班扶眼镜 → 魔杖高速掠过 → 瞳孔映出蓝光 → 杖尖闪白切场。

### 4.17–6.25 秒｜因素

羽毛旋转微距 → 因素抬手 → 羽毛瞬变茶杯 → 杯沿星图爆开 → 圆形传送门吞没画面。

### 6.25–8.33 秒｜三人相遇

图书馆广角 → 罗兰回头 → 因素微笑 → 尚班单手接书 → 冲击波掠过地面 → 魔法碎片旋转遮挡。

### 8.33–10.125 秒｜英雄镜头

三组半秒人物特写交替闪切，随后快速拉远形成三人英雄构图。10.00 秒全乐团重音，蓝金魔法圆环点亮并定格。

## 视觉要求

- 精致电影质感，高对比蓝金色，干净锐利的硬切与匹配剪辑。
- 保持三人脸、年龄、服装和配饰完全一致。
- 快剪只改变镜头尺度、运动速度与剪辑点，不用人物变形制造转场。
- 无字幕、无片名、无水印。
